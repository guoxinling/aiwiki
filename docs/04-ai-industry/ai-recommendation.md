# AI推荐系统

> 千人千面，精准推荐提升转化

---

## 🎯 推荐系统原理

**核心问题**：用户喜欢什么？

### 推荐类型
- **协同过滤**：相似用户喜欢什么
- **内容推荐**：相似商品
- **深度学习**：复杂模式识别

---

## 🛠️ 技术架构

```
用户行为 → 特征工程 → 召回 → 排序 → 展示
```

**关键指标**：
- 点击率（CTR）
- 转化率（CVR）
- 停留时长
