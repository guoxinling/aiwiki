# Claude使用指南

> Anthropic 出品的长文本处理专家，以深度思考和高质量写作著称。

---

## Claude 是什么？

Claude 是 Anthropic（OpenAI 前员工创办）开发的 AI 助手。它的定位不是"什么都会一点"，而是**安全、可靠、善思考**。

| 核心优势 | 什么意思 | 为什么重要 |
|---------|---------|-----------|
| 📚 **超长上下文** | 一次能读一本书 | 传合同、论文、长篇文档分析 |
| ✍️ **写作质量高** | 语言自然，不"AI味" | 写出来的东西更像人写的 |
| 🧠 **深度思考** | 擅长复杂推理 | 数据分析、逻辑推理、代码审查 |
| 🛡️ **安全可靠** | 拒绝胡说不造假 | 宁说不知道也不编答案 |
| 📎 **Artifacts** | 边聊边生成可交互内容 | 网页、图表、代码即时预览 |

---

## Claude 有什么特别？

### 📚 200K 上下文：一次吃下一本书

这是 Claude 最突出的能力。200K Token ≈ 15 万英文单词 ≈ **一本中等厚度的书**。

**实际场景**：

| 你能做什么 | 以前怎么办 | 现在用 Claude |
|-----------|-----------|-------------|
| 读一份 50 页合同 | 自己啃一下午 | 丢给 Claude，30 秒出摘要 |
| 分析 3 个月的聊天记录 | 不可能做到 | 导出后丢给 Claude 找趋势 |
| 对比两本技术文档 | 翻来翻去眼花 | 两本一起传，让 AI 找差异 |
| 翻译整本手册 | 一章章翻译 | 一次全丢进去，风格统一 |

> 💡 **注意**：免费版上下文较小，需要 Pro 版才能用到 200K。

---

### 📎 Artifacts：不只聊天，还能"做东西"

Artifacts 是 Claude 独有的功能——它会直接在对话旁边**生成可交互的内容**。

**能生成什么**：
- 📄 网页（HTML/CSS/JS 即时预览）
- 📊 交互式图表（SVG 图表、流程图）
- 🎮 小游戏、小工具（井字棋、倒计时器、单位换算器）
- 📝 文档、幻灯片
- 🧮 React 组件原型

**怎么用**：只要你说"帮我做一个 X"，Claude 如果判断做出来更好展示，就会自动生成 Artifact。

> 比如你说"设计一个倒计时 App 的界面"，Claude 不只是描述，而是直接生成一个可以点击的网页原型。

---

### 📁 Projects：给 Claude 装一个"知识库"

Projects 是 Pro/Team 版功能，相当于给 Claude 设定一个**专属工作区**。

**一个 Project 包含**：
- 📋 **自定义指令**：设定角色、风格、规则（永久生效，不用每次都写 prompt）
- 📚 **知识库文档**：上传你的资料（产品文档、公司规范、课程笔记等）
- 💬 **专属对话**：在这个 Project 下的所有对话自动引用上述内容

**实用场景**：

| 场景 | 怎么建 Project |
|------|---------------|
| 写公司内部文档 | 上传品牌指南和产品文档，设定"用公司风格" |
| 学一门课 | 上传课程大纲和笔记，让 Claude 当助教 |
| 个人律师助理 | 上传合同模板和相关法规，审查合同时引用 |
| 代码库助手 | 上传代码库文档，所有编程问题都基于你的代码 |

---

### 🖥️ Computer Use（实验性功能）

Claude 可以像人一样操作电脑：移动鼠标、点击按钮、打字输入。

**能做什么**：
- 自动填写网页表单
- 操作复杂的 Web 应用
- 执行多步骤的线上操作

> ⚠️ 目前是实验功能，需要 API 使用，普通用户暂时用不到。

## 快速上手

### 1. 注册账号

1. 访问 [claude.ai](https://claude.ai)
2. 用 Google 邮箱或邮箱注册
3. 验证手机号（**需要境外手机号**，中国大陆号码不支持）

| 功能 | Free 免费版 | Pro $20/月 | Team $30/人/月 |
|------|------------|-----------|----------------|
| 基础对话 | ✅ | ✅ | ✅ |
| 图片识别 | ✅ | ✅ | ✅ |
| 文件上传 | ✅（有限制） | ✅ | ✅ |
| 最新模型 | 限次数 | ✅ 无限制 | ✅ 无限制 |
| Artifacts | ✅ | ✅ | ✅ |
| Projects | ❌ | ✅ | ✅ |
| 200K 上下文 | ❌ | ✅ | ✅ |
| 多人协作 | ❌ | ❌ | ✅ |

**建议**：先用免费版体验，觉得好用再升级 Pro。

---

### 3. 上传文件

Claude 支持上传多种格式：

| 支持格式 | 用途 |
|---------|------|
| PDF | 文档、合同、论文 |
| Word (.docx) | 报告、方案 |
| Excel (.xlsx) | 数据表格 |
| 图片 (.jpg/.png) | 截图、照片、图表 |
| 纯文本 (.txt/.md/.csv) | 代码、数据文件 |

**怎么传**：点击输入框旁边的 📎 图标，或者直接拖拽文件到对话窗口。

## 实际案例

### 案例 1：分析长文档

**场景**：你收到一份 80 页的投资协议，看不懂法律术语。

**操作**：
1. 上传 PDF
2. 输入：`总结这份协议的核心条款，用大白话解释，特别标注哪些条款对我不利`

**Claude 输出**：
- 关键条款清单（白话版）
- 风险条款标红
- 建议修改的地方
- 一张权利义务对照表

---

### 案例 2：对比多份文档

**场景**：你手上有 A 公司和 B 公司两家的竞品分析报告，想找关键差异。

**操作**：
1. 同时上传两份 PDF
2. 输入：`对比这两份报告，用表格列出它们在核心功能、定价、目标用户三个维度的差异`

**Claude 输出**：结构清晰的三维度对比表，附带一句话总结。

---

### 案例 3：批量处理数据

**场景**：你导出了 500 条用户反馈的 Excel，想找共性问题。

**操作**：
1. 上传 Excel 文件
2. 输入：`分析这些用户反馈，按问题类型分类，找出 Top 5 高频问题，统计占比`

**Claude 输出**：
- 分类统计表
- Top 5 问题及占比
- 每类问题的一条典型原文引用
- 改进建议

---

### 案例 4：用 Artifact 做网页工具

**场景**：你需要一个快速换算中美时区的小工具。

**操作**：
```
帮我做一个时区换算器网页：
- 左边选中国时间，右边自动显示美国（东部）时间
- 支持切换 AM/PM
- 设计简洁好看
```

**Claude 输出**：直接生成一个可交互的 Artifact 网页，你可以在右侧面板直接使用。

---

### 案例 5：建个人写作 Project

**场景**：你是小红书博主，想统一所有文案的风格。

**操作**：
1. 创建 Project，命名"小红书文案助手"
2. 在「Project Knowledge」上传你历史的高赞笔记 3-5 篇
3. 在「Custom Instructions」写入：
   ```
   你是一个小红书文案助手。风格要求：
   - 口语化、轻松、有亲切感
   - 每段不超过3行
   - 多用 emoji，但不过度
   - 标题用疑问句或数字开头
   - 结尾加互动引导
   ```
4. 以后所有文案需求都在这个 Project 里对话，Claude 自动按你的风格写

## Claude vs ChatGPT：怎么选？

| 维度 | Claude | ChatGPT |
|------|--------|---------|
| **长文处理** | 🏆 200K 上下文 | ~32K（付费版） |
| **中文写作** | 🏆 更自然，AI味少 | 也不错，稍偏翻译腔 |
| **深度推理** | 🏆 逻辑严密，善于多步推理 | 很强，但偶尔跳过步骤 |
| **创意发散** | 较保守 | 🏆 更敢想更发散 |
| **代码能力** | 很强 | 🏆 略强（有 Code Interpreter） |
| **联网搜索** | ❌（2025 年中之前不支持） | 🏆 支持 |
| **图片生成** | ❌ 不支持 | 🏆 DALL·E 支持 |
| **文件分析** | 🏆 更多格式，更长文档 | 支持，但上下文较短 |
| **安全性** | 🏆 拒绝更谨慎 | 较宽松 |
| **价格** | $20/月 | $20/月 |

**一句话建议**：
- 写文章、读长文档、数据分析 → **Claude**
- 联网搜索、画图、创意发散 → **ChatGPT**
- 预算够 → **两个都用**，互补

## 使用技巧

### ✅ 让 Claude 发挥最大价值的方法

1. **一次给足上下文**
   - 不要说"帮我写个报告"
   - 要上传相关文档，说明背景、受众、格式要求

2. **善用"角色设定"**
   ```
   你是资深数据分析师，帮我分析这份销售数据，
   重点关注季度趋势和异常值，用表格展示
   ```

3. **分步引导复杂任务**
   ```
   第1步：先分析这份数据的整体趋势
   第2步：找出 Top 3 问题区域
   第3步：针对每个问题提出改进方案
   ```

4. **利用 Projects 建私有知识库**
   - 这是 Claude 的独门优势，别只用默认对话！

5. **不满意就让它重来**
   - "换个角度重新分析"
   - "再详细一点"
   - "用表格重新组织"

## 常见问题

**Q：国内怎么用 Claude？**
A：需要境外网络环境和境外手机号验证。如果没有，可以考虑：
- 通过 API 中转服务使用（如 Poe、Cursor）
- 使用国内替代品（Kimi 专注长文，DeepSeek 推理强）

**Q：我的数据安全吗？**
A：Anthropic 在安全方面口碑很好。Pro/Team 用户可以不共享数据用于训练。**但建议不要在对话中发送密码、身份证等极端敏感信息。**

**Q：Claude 能联网吗？**
A：之前不支持，但 2025 年开始逐步推出联网搜索功能（需确认当前状态）。

**Q：免费版够用吗？**
A：轻度使用够。但如果你经常处理长文档或需要 Projects 功能，Pro $20/月很值。
