# RAG系统搭建

> 让AI读懂你的文档，打造专属知识库问答系统

---

## 📚 什么是RAG？

**RAG**（Retrieval-Augmented Generation，检索增强生成）是一种让AI能**基于你的私有数据**回答问题的方法。

### 通俗理解

想象你的AI是一个聪明但知识有限的学生：
- ❌ **普通AI**：只能回答训练时学过的内容
- ✅ **RAG增强的AI**：可以查阅你给的"参考书"，再回答问题

### 工作原理

```
用户提问 → 检索相关文档 → AI结合文档生成回答
```

**三步走**：
1. **索引**：把你的文档切分成小块，转成向量存入数据库
2. **检索**：用户提问时，找到最相关的文档片段
3. **生成**：AI基于检索到的内容，生成准确回答

---

## 🎯 为什么需要RAG？

| 场景 | 普通AI | RAG增强AI |
|------|--------|-----------|
| **公司规章制度** | ❌ 不知道 | ✅ 基于内部文档回答 |

## 🛠️ 核心组件

### 1. 向量数据库（Vector Database）

**作用**：存储文档的"语义向量"

**原理**：
- 把文字转成数字向量（比如768维的数组）
- 相似的内容，向量距离近
- 搜索时找距离最近的向量

**常用工具**：
| 工具 | 特点 | 适用场景 |
|------|------|----------|
| **Chroma** | 轻量、易用 | 本地开发、小型项目 |
| **Pinecone** | 托管服务、高性能 | 生产环境、大规模数据 |
| **Milvus** | 开源、功能丰富 | 企业级应用 |
| **FAISS** | Meta开源、高性能 | 需要深度定制的场景 |

### 2. Embedding模型

**作用**：把文字转成向量

**常用模型**：
- **OpenAI text-embedding-ada-002**：效果好，按量付费
- **BGE（智源）**：中文效果好，开源免费
- **M3E**：中文向量化模型，轻量快速

### 3. 大语言模型（LLM）

**作用**：基于检索到的内容生成回答

**选择建议**：
- **GPT-4/Claude**：效果最佳，成本高
- **GPT-3.5/Kimi**：性价比好，适合大多数场景
- **本地模型**：数据敏感场景，如Llama、ChatGLM

## 📝 搭建步骤

### 步骤1：准备知识库

**收集文档**：
- Word/PDF/Markdown文件
- 网页内容
- 数据库记录
- 聊天记录

**文档处理**：
```
长文档 → 切分成小段（chunk）→ 每段500-1000字
```

**为什么要切分？**
- 提高检索精度
- 减少无关内容干扰
- 降低token消耗

### 步骤2：生成向量并存储

```python
# 伪代码示意
from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import Chroma

# 1. 初始化Embedding模型
embeddings = OpenAIEmbeddings()

# 2. 读取文档并切分
documents = load_and_split_documents("./知识库/")

# 3. 存入向量数据库
vectorstore = Chroma.from_documents(
    documents=documents,
    embedding=embeddings,
    persist_directory="./chroma_db"
)
```

### 步骤3：搭建问答流程

```python
# 检索 + 生成
from langchain.chains import RetrievalQA
from langchain.llms import OpenAI

# 1. 创建检索器
retriever = vectorstore.as_retriever(
    search_type="similarity",
    search_kwargs={"k": 5}  # 检索Top 5相关片段
)

# 2. 创建问答链
qa_chain = RetrievalQA.from_chain_type(
    llm=OpenAI(),
    chain_type="stuff",
    retriever=retriever
)

# 3. 提问
answer = qa_chain.run("公司的年假政策是什么？")
```

### 步骤4：优化效果

**提升检索精度**：
- 添加文档摘要和关键词
- 使用重排序（Re-ranking）
- 混合检索（向量+关键词）

**提升生成质量**：
- 优化提示词模板
- 添加引用来源
- 设置拒答机制（检索不到时不瞎编）

**方案**：

## ⚠️ 注意事项

### 1. 数据安全
- 敏感数据用本地部署的Embedding模型和向量库
- 避免把机密文档传到第三方平台

### 2. 幻觉问题
- RAG不能完全消除AI幻觉
- 设置阈值，检索不到时明确告知用户

### 3. 维护成本
- 知识库需要定期更新
- 文档变动后要重新索引
- 监控问答质量，持续优化

### 4. 成本控制
- Embedding调用按token收费
- 大模型生成也消耗token
- 大规模应用要考虑缓存策略
