# 经典论文导读

> 读经典论文，理解AI发展的关键里程碑

---

## 🎯 为什么读经典论文？

**论文的价值：**
- ✅ **理解原理**：知道技术为什么有效
- ✅ **学习思路**：看研究者如何解决问题
- ✅ **跟踪前沿**：了解领域最新进展
- ✅ **提升能力**：培养科研思维

---

## 📜 深度学习里程碑论文

### 1. ImageNet时刻（2012）

**AlexNet**
- 论文：ImageNet Classification with Deep CNN
- 作者：Alex Krizhevsky et al.
- 意义：深度学习复兴的开端
- 关键点：ReLU、Dropout、GPU训练

### 2. 序列建模突破（2014-2017）

**Seq2Seq** (2014)
- 论文：Sequence to Sequence Learning
- 意义：机器翻译新范式

**Attention is All You Need** (2017)
- 论文：Transformer架构
- 作者：Google
- 意义：NLP革命，大模型基础

### 3. 预训练时代（2018-2019）

**BERT** (2018)
- 论文：BERT: Pre-training of Deep Bidirectional Transformers
- 意义：双向编码器，理解能力飞跃

**GPT系列**
- GPT-1 (2018)：预训练+微调
- GPT-2 (2019)：Zero-shot能力
- GPT-3 (2020)：涌现能力

## 📚 如何读论文

### 阅读顺序

```
1. 标题+摘要 → 判断是否相关
2. 结论+图表 → 快速了解结果
3. 方法 → 理解技术细节
4. 实验 → 验证有效性
5. 相关工作 → 了解背景
```

### 阅读技巧

| 技巧 | 说明 |
|------|------|
| **三遍阅读** | 粗略→详细→深入 |
| **带着问题** | 作者解决了什么问题？|
| **关注创新** | 与之前方法的区别 |
| **验证实验** | 实验设计是否合理？|
