## 🏆 Hugging Face

**最大的AI模型社区**

| 项目 | 内容 |
|------|------|
| **网址** | huggingface.co |
| **模型数** | 50万+ |
| **特点** | 生态完善，文档好 |

**使用：**
```python
from transformers import pipeline

# 一行代码使用模型
classifier = pipeline("sentiment-analysis")
result = classifier("I love AI!")
```
